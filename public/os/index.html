BEFORE YOU START

开始之前

  1. 每个阶段，一份仓库

    每个 GitHub 账号在每个阶段只能创建一个仓库。

  2. 仓库默认公开

    创建的仓库是公开的，代码对所有人可见。

  3. 等待协作邀请

    仓库创建后，请等待 GitHub 发来协作邀请。接受后，即可向仓库推送代码。
